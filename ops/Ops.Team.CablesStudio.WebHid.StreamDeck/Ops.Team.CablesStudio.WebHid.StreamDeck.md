# Ops.Team.CablesStudio.WebHid.StreamDeck

Interfacing natively with Elgato Stream Deck devices using standard browser WebHID API.

## Features
- Compatible with Stream Deck V1, V2, Mini, XL, Mk2, and Plus models.
- Full bidrectional communication: Button press & release events, canvas/texture rendering per key or grid-stretched, and display brightness control.
- Requires no native macOS/N-API binaries; runs pure browser WebHID standard.
- Includes `Request Device` trigger port to launch standard browser WebHID permission selector.
