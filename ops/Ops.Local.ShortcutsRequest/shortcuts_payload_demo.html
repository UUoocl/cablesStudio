How to Set Up Your macOS Shortcut

Create a macOS Shortcut named exactly matching the input field above (e.g. Print Input Object).
Accept Shortcut Input at launch. Add the Get Dictionary from Input action to parse the JSON string.
Extract inputs: use Get Value for "number", "string", and "event" from the Dictionary.
Perform your shortcut logic. Then, extract the callback URL from the input dictionary via key "callback".
Trigger the callback: Add a Get Contents of URL action pointing to the extracted callback URL. Set method to POST, headers Content-Type: application/json, and send a Request Body like: 
"event": "<Value of key 'event'>",
"status": "success",
"result": "YOUR SHORTCUT OUTPUT HERE"
Run the trigger in the playground and watch the terminal log and results display update dynamically.
